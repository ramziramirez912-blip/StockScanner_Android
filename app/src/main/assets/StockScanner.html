Export to Excel

Creates a .xlsx file with all articles (with current stock) and the full movement history.

Import from Excel

Reads a .xlsx file with sheets named Articles, SCAN IN, SCAN OUT or Movements. Works with your Stock_Scanner.xlsx workbook.

Backup

Saves a copy of all data to a file. Do this regularly and keep the file on another drive or USB key.

Restore a backup

Replaces ALL current data with the content of a backup file.

Erase all data

Deletes every article and movement from this computer. Save a backup first.
